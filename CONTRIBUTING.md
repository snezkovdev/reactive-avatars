# Участие в разработке

Спасибо за интерес к Reactive Avatars.

## Сообщить об ошибке

Создайте Issue и укажите:

- версию Windows или другой ОС;
- версию Python;
- точные шаги воспроизведения;
- ожидаемое и фактическое поведение;
- полный текст ошибки;
- пример файлов, если их можно безопасно опубликовать.

Не публикуйте приватные записи разговоров, токены, пароли и другие личные данные.

## Предложить изменение

1. Создайте fork репозитория.
2. Создайте ветку: `git switch -c feature/my-change`.
3. Установите окружение разработчика: `python -m pip install -e ".[dev]"`.
4. Внесите изменение и добавьте тесты.
5. Запустите `ruff check .` и `pytest`.
6. Создайте Pull Request с понятным описанием.

## Правила кода

- Python 3.11+.
- Новая логика должна сопровождаться тестами.
- Не добавляйте в репозиторий аудио, видео, `.ravproj` и пользовательские аватарки.
- Изменения интерфейса желательно показывать скриншотом.
- Один Pull Request должен решать одну связанную задачу.

## Версии

Проект использует семантические версии:

- `PATCH` — исправления без изменения поведения;
- `MINOR` — новые совместимые возможности;
- `MAJOR` — несовместимые изменения формата проекта или API.
