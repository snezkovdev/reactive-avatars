# Политика безопасности

Если вы нашли уязвимость, не публикуйте подробности в открытом Issue. Свяжитесь с владельцем репозитория через приватный канал GitHub Security Advisories.

Проект обрабатывает медиа локально и не отправляет аудио, изображения или проекты на внешние серверы. Зависимости устанавливаются через `pip`, поэтому перед запуском форков и сторонних сборок проверяйте их исходный код и список зависимостей.

Поддерживаются последняя стабильная версия и актуальная ветка `main`.
