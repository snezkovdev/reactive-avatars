REACTIVE AVATARS 2.0
====================

Приложение создаёт прозрачное MOV-видео с аватарками участников. Когда человек
говорит, его аватарка становится ярче, слегка увеличивается, двигается и
загорается зелёным. Если говорят несколько человек, подсвечиваются все.


БЫСТРЫЙ ЗАПУСК

1. На Windows установи Python 3.11 или новее с сайта python.org.
   При установке обязательно включи Add Python to PATH.
2. Дважды нажми START.bat.
3. При первом запуске подожди, пока установятся компоненты интерфейса и рендера.
4. Выбери общую дорожку, количество участников и файлы каждого человека.
5. Выбери место для результата и нажми «Создать прозрачное видео».

После первого запуска интернет программе больше не нужен.


КАК ПОДГОТОВИТЬ ЗВУК

- Общая дорожка — готовый звук всей записи. Только она попадёт в видео.
- У каждого участника должна быть отдельная дорожка, где слышен его голос.
- Отдельные дорожки используются только как датчики активности, их качество
  не влияет на итоговый звук.
- Все дорожки должны начинаться в один и тот же момент. Пустые места не удаляй.
- При одновременной речи оставляй звук на дорожках всех говорящих.
- Длительность видео определяется общей дорожкой.


УЧАСТНИКИ И РАСКЛАДКА

Поддерживается от 1 до 8 участников. Программа сама предлагает раскладку:

1 человек   — по центру
2–3         — один ряд
4           — сетка 2×2
5           — три сверху, два снизу
6           — сетка 3×2
7           — четыре сверху, три снизу
8           — сетка 4×2

Аватарки можно перетаскивать мышкой прямо в предпросмотре. Кнопка
«Автораскладка» возвращает стандартные позиции. Карточки участников также
можно перетаскивать, меняя их порядок.


ИМПОРТ ПАПКИ

Чтобы загрузить всё одним действием, подготовь папку с именами:

master.wav
avatar1.png
voice1.wav
avatar2.png
voice2.wav
...

Расширения могут отличаться. Поддерживаются WAV, MP3, M4A, AAC, FLAC, OGG,
OPUS и изображения PNG, JPG, JPEG, WEBP, BMP. Папку можно перетащить в окно
или выбрать кнопкой «Импортировать подготовленную папку».


АВАТАРКИ

Обычное фото автоматически кадрируется в круг и получает бело-серебристую
обводку. Нажми «Кадрировать» в карточке участника, чтобы настроить масштаб и
положение лица. Готовые прозрачные круглые PNG распознаются и не получают
вторую рамку. Автоматическое оформление можно отключить в настройках.


ЧУВСТВИТЕЛЬНОСТЬ

У каждого участника собственная чувствительность:

1.00 — стандартное значение
1.20 — реагирует на более тихий голос
0.80 — игнорирует больше фонового шума

Обычно достаточно значений от 0.85 до 1.25.


ПРОЕКТЫ

Кнопка «Сохранить» создаёт файл .ravproj. В нём хранятся пути к дорожкам,
аватаркам, кадрирование, чувствительность и расположение. Исходные файлы внутрь
проекта не копируются, поэтому не перемещай их после сохранения.


РЕЗУЛЬТАТ

Результат — MOV с кодеком ProRes 4444 и настоящим альфа-каналом. Его можно
положить поверх любого фона в CapCut, DaVinci Resolve, Premiere Pro и других
редакторах без хромакея. Такой файл может занимать много места — это нормально.


СБОРКА ПОРТАТИВНОГО WINDOWS-ПРИЛОЖЕНИЯ

1. Один раз запусти BUILD_APP.bat на Windows.
2. Дождись BUILD COMPLETE.
3. Открой dist\ReactiveAvatars2.
4. Запускай ReactiveAvatars2.exe.

После сборки Python для запуска приложения не нужен. На другой компьютер
копируй папку ReactiveAvatars2 целиком, а не один EXE.
